# Templates

- **`Template.java`** — canonical. This is the template the committed solutions
  are based on (embedded `Reader`/`Writer`, `solve()` + multi-test `main`).
  Point JHelper's / CPH's "new file" template at this file. Fill in the header
  comment per the [header convention](../../README.md#header-convention) and
  delete the trailing notes block at the bottom once you've read it.

- **`archive/`** — older/heavier templates (`Template1`, `Template2`,
  `TemplateDebug`, `TemplateUwi`) kept for reference (extra data structures,
  debug helpers, etc.). Not used as the default starting point; copy snippets
  out of these into a solution as needed.
